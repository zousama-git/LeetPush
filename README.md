# LeetPush

LeetPush is a zero-click browser extension (Edge/Chrome) that automatically exports your accepted LeetCode solutions directly to your GitHub repository.

## Features
* **Zero-Click Automation**: Intercepts successful submissions instantly.
* **Multi-Solution Handling**: Auto-versions repeated problem attempts (`Solution.java`, `Solution_v2.java`).
* **Minimalist UI**: Monospace terminal aesthetic matching system dark/light modes.
* **Difficulty Counter**: Tracks Easy, Medium, and Hard problem metrics locally.

## Setup Instructions
1. Clone repository and open `edge://extensions/`.
2. Enable **Developer mode** and select **Load unpacked**.
3. Target folder containing extension files.
4. Input GitHub Token (PAT), Username, and Repository name in the popup.
